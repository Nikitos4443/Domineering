### Domineering game

This is a Domineering game built using React and TypeScript, 
featuring an AI opponent powered by the Minimax algorithm.

## Game Rules:
- You play as Red and can place horizontal lines.
- Your opponent plays as Blue and can place vertical lines.
- Lines cannot touch each other.
- The game ends when a player has no moves left.
- The player who makes the last move wins

You can play it at the link:
https://domineering-u2t5.vercel.app/
